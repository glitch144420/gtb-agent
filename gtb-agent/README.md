# 🚀 Project Forge Agent

An open-source AI agent that automates the creation of complete project structures based on natural language descriptions.

## ✨ Features

- 🤖 **Multi-Agent Architecture** - Orchestrator LLM + specialized tools
- 💬 **Conversational Interface** - Chat-based interaction
- 🔌 **Multi-LLM Support** - OpenAI, Anthropic, Gemini, AWS Bedrock
- 🖼️ **Batch Image Generation** - Replicate, DALL-E, AWS Bedrock
- 📁 **Automatic File Extraction** - Creates folder structures from AI responses
- 📄 **PDF Documentation** - Auto-generates project summaries
- 📦 **One-Click Download** - Get projects as ZIP files
- ☁️ **AWS Integration** - Optional Bedrock, S3, Lambda support
